How to read this page

Each card shows the name of the state or union territory, the two letters its vehicles carry, and how many registering offices VAHAN lists for it. Tap a card to open the full list for that state: every code, the office it belongs to, and a box to search by code or town.

Why the counts differ so much

The number of offices says how a state has divided the work, not how many vehicles it has. Some states give a separate code to every sub-division or taluk office; others keep one code for a whole district. As on 11 November 2026 the longest lists are Himachal Pradesh (116), Haryana (98), Punjab (96), Kerala (87), Uttar Pradesh (75). Andaman and Nicobar Islands and Chandigarh have a single office each.

The count here is of codes below 200, which are the ones seen on number plates. VAHAN also carries higher numbers for some states, used for units such as fitness centres; each state page shows those separately.

What a code tells you, and what it does not

The code on a plate names the office where the vehicle was first registered. It does not say where the owner lives now, or where the vehicle is kept. A car bought in one city and driven for years in another keeps its first code unless the owner has it registered again after moving to another state.

  • Know the code already? Type it, or the whole vehicle number, in the RTO code finder.
